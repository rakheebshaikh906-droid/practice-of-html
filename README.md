# HTML Practice

A collection of HTML projects, exercises, and practice files created while learning web development fundamentals. This repository documents my journey of mastering HTML by building different web pages and exploring various HTML elements, tags, and structures.

## Overview

This repository contains hands-on HTML practice examples ranging from basic page structures to more advanced layouts. The goal is to strengthen core web development skills and build a solid foundation for learning CSS, JavaScript, and modern frontend frameworks.

## Topics Covered

* HTML Document Structure
* Headings and Paragraphs
* Text Formatting Tags
* Lists (Ordered & Unordered)
* Hyperlinks
* Images
* Tables
* Forms
* Semantic HTML
* Audio and Video Elements
* HTML5 Features
* Practice Projects

## Getting Started

Clone the repository:

```bash

```

Navigate to the project folder:

```bash
cd practice-of-html
```

Open any `.html` file in your browser to view the output.
